# Contributing

Start with a real application operation and an authoritative ABI definition.
Do not add speculative adapters or raw arbitrary-export invocation.

Pull requests must include:

- adapter manifest and provenance for the ABI;
- generated or custom marshalling tests;
- buffer, timeout, cancellation and stale-handle cases;
- an honest capability/limitation update;
- no credentials, proprietary SDK files, game files, or account data.
